Mission control gauges

Each gauge is one page. The link carries the numbers, so nothing is stored here. Put a link in a Notion /embed block. To show a new reading, change the link.

Shared settings

  • value, min, max, unit, label: the reading and its words.
  • look, broken: limits that turn the gauge amber or red. Add good=low when smaller is better.
  • state=fine|look|broken|unknown: set the state yourself.
  • accent=f2a33a: the project colour (hex, no #). updated= an ISO time adds "checked … ago".
  • By default a gauge has no backdrop, so it sits on the Notion page like text. It follows the page's light or dark theme. theme=light|dark forces one.
  • bg=191919 (a hex): draw the gauge as a card on that colour instead.
